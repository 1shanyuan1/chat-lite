# UI 实验版（ui-next）

只做一件事：把 [UI 设计评审](../../docs/ui-design-review.md) 里的重设计建议做成**可以真实使用的版本**来评估效果。
与正式版**共用同一份 store、聊天引擎和本机数据**——两边打开的是同一批会话与设定，改设置也互通，
唯一的差别是渲染层。

> **外观系统已回灌正式版**（2026-11-21）：色组即外观（17 预设 + 自定义三表面 + 字体颜色）、
> 消息气泡模式、直角无例外——实现提升到共享层（`src/ui/palette.ts`、`src/ui/PalettePicker.tsx`），
> 正式版与实验版共用同一实现。实验版保留的是**布局与控件的重设计**（聊天页、起始页、抽屉、寄存区、
> 设置面板的版式），评估通过后再走同样的回灌流程。

## 怎么打开

```bash
npm run dev
# 正式版
open http://localhost:5173/
# 实验版
open http://localhost:5173/ui-next.html
# 带演示数据（与正式版同一套 demo）
open http://localhost:5173/ui-next.html?demo=markdown
```

正式版入口 `index.html` / `src/main.tsx` / `src/App.tsx` **一行未动**。
`ui-next.html` 只被 dev server 服务：`npm run build` 只认 index.html，APK 打包（cap:sync）也永远只带正式版。
想在真机上试实验版，需要先把它加进 `vite.config.ts` 的 `build.rollupOptions.input` 再打包——评估阶段不建议。

## 实验了什么（对照评审报告的建议）

| 建议 | 实验版的做法 |
|---|---|
| P0 字阶收敛 | 只保留 5 档：22 展示 / 17 标题 / 16 正文 / 14 界面 / 12 辅助。全版不再出现 9–11px |
| P0 灰度纪律 | 正文 neutral-800、界面默认 neutral-600、辅助 neutral-500；neutral-400 只做占位/禁用；不再用 -300/-400 当文字 |
| P1 圆角收敛 | 两族：`rounded-2xl`（卡片/面板/气泡/弹层/输入条）+ `rounded-full`（胶囊/圆钮/搜索框）；头像缩略图用 8px |
| P1 控件统一 | 次级动作全部是胶囊（h-7=12px 字）；选中黑底白字、默认灰底、危险红字；设置面板分段选择器替代两行按钮 |
| P1 附属层收敛 | 每条回答从 4 层附属物收敛为「一行操作胶囊 + 一行元信息 + 可展开详情」；赞踩和完整用量收进详情层 |
| P1 列表行统一 | ProviderPicker / ModelPicker / AuxModelPicker / 会话行统一为 px-3 py-2.5、14px 主文字、12px 元信息 |
| P2 设置重排 | 按「外观 / 连接 / 行为」三节分组，12px 小节标题 + 间距分节（去掉细线切割） |
| 新增：色组即外观 | 浅色/深色不再有独立开关——**色组就是外观**：预设 17 个 = 6 色相 × 浅/深（石墨 / 靛蓝 / 松柏 / 胭脂 / 琥珀 / **鲜艳**，浓度 0–65）+ **5 个纯色强对比**（曜黑 / 藏青 / 墨松 / 酒红 / 牛皮纸，底色用真正的纯色）。叠块按真实配色渲染，深色组自己就是深色的；「自定义」面板里**浅/深两套锚点各自独立存储**（明暗切换编辑的就是那一套），**三层表面模型**：主色刷大块面积（页面底/浅面板），中间色刷中层表面（**气泡、输入框**、边框），墨色刷小部件（主按钮/激活态），另有字体颜色（正文 / 次级 / 辅助）三路独立覆盖——每个颜色只管自己的一层，**显式选择原样生效，改任何一个颜色其它层一个像素都不变**（分域直管，实测验证）；只有缺省推演的文字色走可读性明度域。全部写进 `--color-*` 变量，**所有组件一起变**（`palette.ts`，不用 color-mix 以兼容老 WebView；旧 {h,s} / 扁平格式读取时兼容） |
| 新增：消息气泡模式 | 外观里「消息样式：平铺 / 气泡」可切换——气泡模式下助手回复也装进气泡（左上小圆角区分方向），平铺保持纯正文（`config.bubbles`） |
| 全局外观 | 直角模式**无例外**：连胶囊、分段器一起归零（`ui-next.css` 覆盖正式版保留 `.rounded-full` 的规则）。深浅主题本就走全局变量，无组件级例外 |
| P2 起始页 | 模式卡提示文字限两行，三卡高度一致；列表行统一密度 |
| 危险操作 | 删除类固定红字（red-600），不再用 neutral-300 的「隐形删除」 |

保持不变的：主题变量架构（深色/直角仍由 `data-theme` / `data-corners` 全局生效）、
所有交互逻辑与状态语义、横滑修复（overflow-x-hidden + overflow-wrap + 表格横滚层）。

## 评估清单

1. 同一份数据下并排开两个入口，先看**聊天页**：正文是否更突出、附属物是否不再抢戏；
2. 深色主题下检查新灰度（设置 → 外观 → 深色）；
3. 直角模式下看圆角两族归零是否仍然成立；
4. 打开一条带搜索/思考的回答，展开「详情」看赞踩与用量；
5. 起始页三张模式卡与列表行密度；
6. 设置面板三节扫读效率。

## 已知取舍

- 设置面板的「部分改动即时生效、部分要保存」语义没动（行为变更，超出视觉实验范围）；
- 没有引入品牌强调色（报告建议只加一个，先验证单色系统收敛的效果，强调色留到下一轮）。
